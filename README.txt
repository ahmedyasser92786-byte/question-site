مهم:
هذه نسخة تجريبية تعمل محليًا داخل المتصفح باستخدام LocalStorage، لذلك بيانات الزوار لا تنتقل بين أجهزتهم.
لكي يصبح الموقع حقيقيًا برابط عام وتصل إجابات كل الناس إليك، يحتاج إلى قاعدة بيانات + استضافة + نظام تسجيل دخول آمن للأدمن.
